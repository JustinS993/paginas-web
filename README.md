# Corte & Sabor

Sitio web de **Corte & Sabor**, una carnicería artesanal. El proyecto reúne una página de presentación y varias pantallas para explorar cortes, consultar ofertas y gestionar un pedido.

## Páginas

- **Inicio:** `sitio-web/index.html`
- **Página principal:** `sitio-web/pagina-principal/code.html`
- **Catálogo de cortes:** `sitio-web/catalogo-de-cortes/code.html`
- **Detalle del corte:** `sitio-web/detalle-del-corte/code.html`
- **Carrito de pedidos:** `sitio-web/carrito-de-pedidos/code.html`
- **Ofertas y packs parrilleros:** `sitio-web/ofertas-y-packs-parrilleros/code.html`

Las carpetas de las pantallas que cuentan con una imagen de referencia también incluyen un archivo `screen.png`. La guía visual está en `sitio-web/guia-de-identidad/DESIGN.md`.

## Cómo ver el sitio

No se requiere instalación ni compilación. Abre `sitio-web/index.html` en un navegador para ver la página de inicio. Las pantallas individuales también pueden abrirse directamente desde sus respectivas carpetas.

## Tecnologías

- HTML
- Tailwind CSS mediante CDN
- Google Fonts y Material Symbols
